# Big Data - Week 2 Assignment

## Overview

This assignment uses **Google Cloud Platform (GCP)** services to process a text file stored in **Google Cloud Storage (GCS)**.  
The goal is to identify the **longest line(s)** in the file based on character length. If multiple lines share the maximum length, all of them are reported.  

The processing is performed entirely on a **Compute Engine Virtual Machine (VM)**.

## Files in this Submission

### 1. `longest_lines.py`

- **Purpose:**  
  Python script that implements the logic.
- **What it does:**  
  1. Downloads the input file from a GCS bucket.  
  2. Reads the file line by line and calculates the length of each line.  
  3. Identifies the longest line(s).  
  4. Prints the results in the VM terminal.  
  5. Saves the results into an output file and uploads it back to the GCS bucket.  

---

### 2. `input.txt`

- **Purpose:**  
  Sample input text file that is stored in the GCS bucket and processed by the script.
- **Contents:**  
  Plain text with multiple lines of varying lengths.  
- **Usage in pipeline:**  
  This file is downloaded by `longest_lines.py` and analyzed to determine the longest line(s).

---

### 3. `longest_lines_output.txt`

  Output generated by the Python script after analyzing the input.  

- **Contents:**  

  - The source file name and path.  
  - Maximum line length (in characters).  
  - Number of lines with that maximum length.  
  - Each longest line, with its line number and content.  

## Pipeline

1. **Storage**: `input.txt` uploaded to a GCS bucket.  
2. **Compute**: A Compute Engine VM runs `longest_lines.py`.  
3. **Processing**: Script downloads the input, finds longest lines, and writes results.  
4. **Output Storage**: Results (`longest_lines_output.txt`) are uploaded back to the GCS bucket.
