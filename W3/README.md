# Big Data - Week 3 Assignment

## Overview

This assignment uses **Google Cloud Functions** to automatically process text files uploaded to **Google Cloud Storage (GCS)**.  
The goal is to identify the **longest line(s)** in each uploaded file based on character length.  
If multiple lines share the maximum length, all of them are reported.  

The processing is **serverless** — it runs automatically whenever a file is uploaded to the GCS bucket, without manual execution.

---

## Files in this Submission

### 1. `w3_longest_lines.py`

- **Purpose:**  
  Core Python script implementing the Cloud Function.

- **What it does:**  
  1. Triggered automatically when a file is uploaded to a specified GCS bucket.  
  2. Downloads the uploaded text file to a temporary directory.  
  3. Scans the file line by line to find the longest line(s).  
  4. Logs the results using **Cloud Logging**.  
  5. Uploads a summary result file back to GCS with the suffix `_longest_lines.txt`.

---

### Input Files

Input text files that are analysed to find the longest lines 

---

### Output Files

- **Purpose:**  
  Output generated by the Cloud Function.  

- **Contents:**  
  - Source file path (`gs://...`)  
  - Maximum line length (in characters)  
  - Number of lines matching that length  
  - Each longest line with its line number and content  

---

## Pipeline

1. **Upload**: A `.txt` file is uploaded to a GCS bucket.  
2. **Trigger**: Upload event triggers the Cloud Function `gcs_longest_lines`.  
3. **Processing**:  
   - The function downloads the file.  
   - Identifies the longest line(s).  
   - Logs results in Cloud Logging.  
4. **Output Storage**:  
   - A new result file `<original_name>_longest_lines.txt` is created and uploaded back to the same GCS bucket.  

---

## Notes

- The function automatically skips previously generated result files to prevent recursive triggers.
