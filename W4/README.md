# Big Data - Week 4 Assignment

## Overview

This assignment uses Google Cloud Dataproc and PySpark to process clickstream data stored in Google Cloud Storage (GCS).
The objective is to calculate the total number of clicks that occurred in four time-of-day intervals:

0–6 hours, 6–12 hours, 12–18 hours, 18–24 hours.

The task is implemented twice — once using the RDD API and once using the DataFrame API.
Both solutions are executed on a Dataproc cluster, with GCS serving as both input and output storage.

---

## Files in this Submission

### Notebooks-

#### 1. `W4GA_RDD.ipynb`

- **Purpose:**  
  Implements the click count computation using RDD transformations and actions.

- **What it does:**  
  1. Reads the input text file from GCS.
  2. Extracts the hour from each timestamp.
  3. Maps each hour into one of four predefined time bins.
  4. Uses map, filter, and reduceByKey to count clicks per bin.
  5. Writes the final results back to GCS as a text file.

#### 2. `W4GA_DF.ipynb`

- **Purpose:**  
  Implements the same click count computation using PySpark DataFrames.

- **What it does:**  
  1. Reads the CSV file with headers into a Spark DataFrame.
  2. Converts the timestamp to a Spark timestamp type and extracts the hour.
  3. Uses conditional expressions (when, otherwise) to map hours to time bins.
  4. Performs aggregation using groupBy and count.
  5. Writes results back to GCS as a CSV with headers.

### Input File `click_file.txt`-

- **Purpose:**   Input file containing sample click data.

- **Contents:**  

    `user_id,timestamp` (format: YYYY-MM-DD HH:MM:SS)

    Example entry:

## Pipeline

1. **Upload**: The input file (click_file.txt) is uploaded to a GCS bucket.
2. **Job Submission**: The Spark Jobs are executed on a Dataproc cluster with Jupyter notebooks.
3. **Processing**:  As explained above.
4. **Output**: Aggregated results are stored back to GCS.
