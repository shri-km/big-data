# Big Data - Week 7 Assignment

## Overview

This assignment demonstrates a streaming pipeline on GCP using Kafka and Spark Structured Streaming, with each
component running on a separate resource.

A Kafka broker with manually installed Kafka is setup on a dedicated VM, Producer 1 to the Kafka topic runs on a separate VM, Producer 2 runs on a Cloud Function that is triggered every 5 seconds, and the PySpark Job that prints the count of rows seen in the last 10 seconds runs on a Dataproc cluster.

## Files in this Submission

### Setup Scripts `kafka_broker_init`

`1_setup_kafka.sh` - Installs Java and sets up Kafka.
`2_config_and_start.sh` - Automatically modifies the config file and starts a Kafka server (daemon) with KRaft storage.
`3_create_topic.sh` - Creates a new topic.
`4_consumer_console.sh` - Consumes messages and logs them to the console.

### Producer VM Setup - `producer1_vm_init.sh`

Installs necessary packages, creates new virtual environments and installs necessary python packages.

### Input Files - `input/`

2 csv input files generated by the python script.

### `generate_input.py`

Python script used for generating input files

### `producer1_vm.py`

Python script for producer that runs on the VM. Produces batches of 10 messages every 10 seconds to the Kafka topic.

### `producer2_cf.py`

Python script for producer that runs on the Cloud Function. Produces batches of 5 messages every time it is triggered.

### `trigger_cf.py`

Python script used to trigger the Cloud Function every 5 seconds.

### `spark_consumer.py`

Run as a PySpark job. Consumes messages from the Kafka topic every 5 seconds in a 10 second window and logs the number of messages in that window.

### `logs.log`

Output logs from the PySpark job.

## Pipeline Overview

Check the screencast for a fully detailed explanation.

- Setup the Kafka VM and Producer VM with the help of the scripts.
- Create a new Kafka topic and consume in a shell. Ping and check it with the Producer VM.
- Deploy the Cloud Function.
- Generate input files with the python script.
- Upload the input files and the PySpark consumer script to GCS.
- Submit the PySpark job.
- Start the Producer script on the VM and run the python script to trigger the Cloud Function every 5s.
